# linux终端下解决广工GDUT校园网连接问题

在 Linux 终端登录广工校园网，支持开机自动连接、退出登录和延迟测试。网卡和 IP 自动识别，无需固定为鲁班猫 5 的配置。

## 使用

先让设备接入校园网，再安装依赖。以 Debian/Ubuntu 为例，其他发行版请使用对应的包管理器：

```bash
sudo apt update
sudo apt install -y python3 curl iproute2 iputils-ping
```

把 `gdut-login.py` 复制到设备，在文件所在目录运行（需要 Python 3.6 或以上）：

```bash
sudo python3 gdut-login.py
```

首次运行会提示输入账号密码，随后自动保存配置、登录并设置开机连接。JSON 配置和服务文件都会自动生成。

以后运行同一命令，会显示菜单，可以连接、退出登录、查看状态或修改账号。退出登录会同时关闭开机自动连接，再次选择连接即可恢复。

## 命令选项

也可以直接指定操作，例如退出登录：`sudo python3 gdut-login.py --logout`。

| 选项 | 作用 |
| --- | --- |
| `--setup` | 保存或修改账号密码，不切换当前登录的账号 |
| `--login` | 连接并开启开机自动连接 |
| `--logout` | 退出登录并关闭开机自动连接，保留账号密码 |
| `--status` | 查看联网状态和延迟，完成后退出 |
| `--once` | 检查网络，需要时登录，完成后退出 |
| `--daemon` | 在前台持续检查网络，供后台服务调用 |
| `--help` | 查看帮助 |

菜单和开机服务需要 systemd。没有 systemd 的系统，可先用 `--setup` 保存账号，再用 `--once` 登录；开机启动需自行配置。

## 工作方式与文件

脚本自动识别通往认证服务器的网卡和 IP，模拟网页登录。后台每分钟检查一次网络，掉线后尝试重连，连续失败 3 次就停止并提示；需要时可用 `--login` 重新启动。

连接成功后测试百度、哔哩哔哩、腾讯和阿里云的延迟。每站发送 3 个包，最多等待 12 秒，测试结束后自动停止 ping。网站不回应 ping 不一定代表断网。

| 文件 | 作用 |
| --- | --- |
| `/usr/local/sbin/gdut-login.py` | 自动复制的脚本，负责登录、注销和联网检查 |
| `/etc/gdut-login/credentials.json` | 自动生成的账号密码配置，仅 root 可读 |
| `/etc/systemd/system/gdut-login.service` | 自动生成的开机服务，在后台运行脚本 |

## 已知限制

- 基础登录已在鲁班猫 5 / Debian 11 验证，其他系统和板卡尚未实测。
- 仅支持 IPv4，依赖完整的 iproute2，不兼容精简版 BusyBox ip；缺少可用的 ping 时会跳过延迟测试。
- 注销接口尚未在广工网关实测。无法确认退出时会提示，自动连接仍会关闭。
- 联网判断依赖百度 HTTP 页面，页面变化可能导致误判。
- 密码以明文保存在本机，校园网认证使用 HTTP。
